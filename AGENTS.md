# NICHEPULSE — Instructions & Règles Globales

## 🎨 UI/UX Design System : Application Systématique de UI/UX Pro Max
Pour toute tâche d'interface utilisateur, de composants, d'expérience utilisateur (UX) ou de style sur ce projet :
1. Consulter et appliquer les recommandations de `ui-ux-pro-max` (`.agents/skills/ui-ux-pro-max/`).
2. Utiliser le script de recherche local si nécessaire :
   ```bash
   python3 .agents/skills/ui-ux-pro-max/scripts/search.py "<query>" --domain <domain>
   ```
3. Respecter les principes :
   - Thème Dark Obsidian Télémétrie haute fidélité (fond sombre profond `#0a0c10` / `#111319`, bordures subtiles `#1e2230`, accents Electric Violet `#7c3aed`, Cyber Cyan `#06b6d4`, Emerald Signal `#10b981`).
   - Règle 60-30-10, contraste WCAG AA, polices professionnelles (Plus Jakarta Sans, JetBrains Mono, Inter).
   - Micro-interactions, animations soignées, indicateurs de momentum et visualisations riches.
